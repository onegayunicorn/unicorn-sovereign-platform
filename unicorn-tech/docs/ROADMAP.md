# 12-Month Roadmap (Oct 2026 – Sep 2027)

- Months 1-2: Freeze terminology, establish repo governance, software-only photonic models, schemas, lab equipment candidates, safety checklist
- Months 3-4: Local optical bench, detector timestamp ingestion, source/detector calibration, negative controls, first evidence bundle
- Months 5-6: Two-node short-fiber link, timing sync, repeated CHSH, secure node enrollment, signed manifests, independent review
- Months 7-8: Environmental monitoring, automated calibration, second regional lab node, degraded-link testing, registry + telemetry dashboard
- Months 9-10: 3-5 node regional pilot, scheduled multi-node experiments, uptime/loss/drift/reproducibility metrics, security/safety/ops reviews
- Months 11-12: Inter-region feasibility study, fiber/free-space/satellite options review, global cost/risk model, measured capability report, go/no-go decision
