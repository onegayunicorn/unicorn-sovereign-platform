# Implementation status and evidence classification

This archive implements useful local paths and interfaces, but it does not claim that every
subsystem is production-ready or physically deployed.

| Area | Included behavior | Classification |
|---|---|---|
| Bell/CHSH | Local deterministic-seed simulation and negative-control harness | Simulated |
| PQC | Provider interface; optional library integration must be installed and validated | Prototype |
| Photonics | Mock source/detector/timing interfaces and metrics | Simulated |
| Quantum jobs | Circuit model, state-vector simulator, job lifecycle | Simulated |
| AI orchestration | Registry, explicit permissions, deny-by-default tool access | Prototype |
| NPC | Original fictional character and sandboxed dialogue/state logic | Prototype |
| Transfers | State machine and integrity metadata contracts | Prototype |
| Cloud/edge | Worker contracts and policy scaffolds | Prototype |
| Automation | Read-only external API monitoring; credentials optional | Prototype |
| Physical network | No physical entanglement claim | Proposed |

Promote any claim to Demonstrated only when raw measurements, calibration records, repeatable
runs, negative controls, pinned code/dependencies, and independent review are retained.
