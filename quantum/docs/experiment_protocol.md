# Experiment Protocol

Every claimed entanglement result must include: experiment ID, node IDs and locations,
source/detector/firmware/software versions, calibration records, basis-selection method,
timestamping method, coincidence-window definition, raw detection-event data,
accidental-coincidence estimate, visibility, CHSH statistic, statistical method + CI,
detector/channel efficiencies, environmental conditions, negative-control results,
analysis code + dependency lockfile, independent review status, evidence classification.
