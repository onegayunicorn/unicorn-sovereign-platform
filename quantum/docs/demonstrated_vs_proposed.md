# Demonstrated vs Proposed — Evidence Classification

| Label | Meaning |
|-------|---------|
| Demonstrated | Reproduced under defined conditions with retained raw evidence |
| Prototype | Implemented or partially tested, not yet independently reproduced |
| Simulated | Produced by a model or simulator |
| Reported | Supplied by external system/partner, not independently verified |
| Proposed | Design concept without experimental confirmation |

No proposal should be described as operational until raw measurements, calibration data,
reproducible procedures, and independent review support it.
